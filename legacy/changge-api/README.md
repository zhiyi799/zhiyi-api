# 长歌 API 源码存档

这里存档的是 Karen（长歌）于 2024 年自己编写的「长歌 API」原始源码，原样保留，未做改动：

- `web/`：站点首页（ideax.html）与接口文档页示例（API文档.html），来自 API.zip。
- `php/`：Change API 的 PHP 骨架（index.php、main.json 接口清单、调用统计、yiyan 接口占位），来自 Change_API.zip。

说明：这套源码是一个以 main.json 配置驱动的接口站架子，当年配套的线上服务（change.bkm.asia）已下线，存档仅作纪念与参考。本仓库主项目「知意 API」是其精神续作：同样的免费接口站形态，接口已全部重新实现并可直接运行。
